Kết nối GitHub

Để nút Lưu ghi được lên trang, bạn cần một mã truy cập GitHub. Mã chỉ lưu trong trình duyệt này.

  1. Đăng nhập GitHub bằng tài khoản thanhdat-designer, mở trang tạo mã.
  2. Token name: portfolio-dashboard. Expiration: chọn 1 năm.
  3. Repository access: Only select repositories, chọn portfolio.
  4. Permissions > Repository permissions > Contents: Read and write.
  5. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) và dán vào ô dưới.
